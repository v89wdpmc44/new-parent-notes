# 只喝鸡汤不吃鸡肉行吗？

> 更新时间：2026-09-15 (UTC+8)

只喝鸡汤不吃鸡肉行吗？更新时间:2023-09-12

只喝鸡汤不吃鸡肉这种饮食习惯并不健康，原因如下：

1. 营养成分不均衡：鸡汤本身含有较少的蛋白质和较丰富的胶原蛋白，如果只喝鸡汤不吃鸡肉，会导致摄入的营养成分不均衡，缺乏肉类和蛋白质等营养物质。

2. 易造成脂肪过剩：虽然鸡汤中脂肪含量较低，但是如果只喝鸡汤不吃鸡肉，会摄入大量的油脂，导致脂肪摄入过多，增加肥胖和的风险。

3. 难以满足正常营养需求：人体正常所需的营养素种类和数量是有限的，只喝鸡汤不吃鸡肉不能满足人体对各种营养素的需求，长期如此可能导致。

4. 不利于健康：鸡肉富含高质量蛋白质、必需氨基酸和不饱和脂肪酸等有益物质，对人体健康有诸多益处。如果只喝鸡汤不吃鸡肉，将无法摄取这些有益物质。

综上所述，只喝鸡汤不吃鸡肉这种饮食习惯不利于人体健康。因此，建议在饮食中适量摄入鸡肉和鸡汤，以摄取充足的营养物质。需要进一步检查确定病因，并进行相应的治疗。须听从医生医嘱并给予相对应治疗。避免导致出现病情加重。当身体出现这种状况的时候，建议及时的去医院进行就诊，并且根据实际情况来进行相应的治疗，避免导致出现症状加重对于身体来说造成的影响和损伤。
