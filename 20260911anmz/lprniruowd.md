# 【“药”你知道】孕妈感冒别硬扛，安全用药更健康

> 更新时间：2026-09-11 (UTC+8)

**“药”你知道**上世纪60年代欧洲出现了数万名畸形婴儿——“海豹儿”，研究发现是孕妇服用沙利度胺所致，这就是因忽视药品安全性而付出惨痛代价的“反应停事件”。1979年，美国食品药品监督管理局（FDA）根据药物对胎儿的危害性，将其分成**A、B、C、D、X ** 5个等级，且安全性逐级下降，其中X级为禁用级别。具体如下表：

**一、发热了怎么办？**

1.  体温不超过38.5℃，可物理降温（如温水擦浴，冷毛巾湿敷、小面积擦拭酒精等方式退热）。

2. 体温超过38.5℃，可服用退热药物。对于孕妈妈，推荐使用单一成分的对乙酰氨基酚（B级），4-6小时用药一次，24小时内不得超过4次，**一日量不宜超过****2g****，退热疗程一般不超过****3****天。**

**二、鼻塞、流涕如何缓解？**

鼻塞流涕是鼻充血的表现，症状不严重可加热加湿空气治疗鼻充血，生理盐水鼻喷剂可缓解症状。 当非药物手段不能控制时，首选局部给药，如0.06%异丙托溴胺鼻喷雾剂（B级）、吸入型色苷酸钠（B级）。若局部用药效果不佳，可口服氯雷他定、西替利嗪（B级）。**注意：**吸入型色苷酸钠可引起短暂性支气管痉挛、咽部刺激和咳嗽，既往有哮喘病史的患者慎用。

**三、咳嗽咳痰能吃什么药？**

止咳化痰药物一般不推荐妊娠妇女使用，对于急性咳嗽，用蜂蜜或含蜜蜂制剂治疗可降低咳嗽频率及严重程度。干咳时可选用右美沙芬（C级），**但妊娠****3****个月以内，哺乳期妇女禁用**。痰液稀释可选用乙酰半胱氨酸（B级）。

**四、感冒了要用抗生素吗？**

普通感冒是一种自限性疾病，多由病毒感染引起，抗生素不能杀灭病毒，所以使用抗生素是无效的。但如果明确合并有细菌感染，伴有脓涕或咳黄脓痰、耳力下降、耳部疼痛等症状，考虑有肺炎、鼻窦炎或中耳炎时，可以使用抗生素。

**五、孕妈该如何预防感冒？**

1. 勤洗手，注意卫生。

2. 适当锻炼，增强体质，生活规律，改善营养状态。

3. 避免受凉或过度劳累，不要去人员密集场所。

4. 注意休息，保持室内空气流通，避免继发细菌感染。

**六、孕妈感冒一般原则**

1. 适当休息，多饮水，清淡饮食。

2. 必须用药时，应根据孕妇病情需要，选用有效且对胎儿比较安全的药物。

3. 尽量单独用药，避免联合用药。

4. 严格掌握剂量和用药时间，注意及时停药。

5. 妊娠早期（前3个月）尽量避免用药。

6. 即使是同一药物，在不同孕期其安全性也不相同，用药前请咨询专业人员。
